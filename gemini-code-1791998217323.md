# TECHNICAL HANDOFF SPECIFICATION: BRICKDECK 2D

## 1. Arquitectura de Directorios
```text
src/
├── app/
│   ├── layout.tsx
│   ├── page.tsx                  # Hub principal, selector de juegos y tienda
│   └── play/[gameId]/page.tsx    # Contenedor dinámico de mesa de juego + tutorial
├── components/
│   ├── ui/                       # Botones estilo bloque, modales, barra de Piezas (Studs)
│   ├── cards/
│   │   ├── Card2D.tsx            # Renderizador SVG 2D de carta (anverso/reverso)
│   │   ├── SuitIcon.tsx          # Iconos vectoriales: Medieval, Futurista, Héroes, Cavernícolas
│   │   └── MinifigArt.tsx        # Ilustración 2D modular para rangos 10, 11, 12 y 13
│   ├── tutorial/
│   │   ├── TutorialOverlay.tsx   # Máquina de estados de partida guiada paso a paso
│   │   └── QuickRulesModal.tsx   # Resumen visual antes de jugar
│   └── games/
│       ├── mus/MusTable.tsx
│       ├── blackjack/BlackjackTable.tsx
│       ├── klondike/KlondikeTable.tsx
│       └── spider/SpiderTable.tsx
├── core/
│   ├── types/card.ts             # Contratos de datos de cartas, palos y variantes
│   ├── deck/deckFactory.ts       # Generador y barajador (Fisher-Yates) para 40, 52 y 104 cartas
│   ├── engines/
│   │   ├── musEngine.ts          # Lógica de Grande, Chica, Pares, Juego/Punto, IA y 4/8 Reyes
│   │   ├── blackjackEngine.ts    # Cálculo de manos (As 1/11), turnos de bots y crupier
│   │   ├── klondikeEngine.ts     # Validación de pilas alternas, fundación y robo 1/3
│   │   └── spiderEngine.ts       # Validación de secuencias del 13 al 1 y detección de escaleras
│   └── tutorials/
│       └── tutorialScripts.ts    # Mazos predefinidos y pasos obligatorios para cada juego
└── store/
    └── useGameStore.ts           # Zustand: saldo de Piezas, inventario, configuración de partida
